## 2. 三个服务各自的关键依赖

### Ingress

`trade-ingress/pom.xml` 直接依赖：

- `mtx-id`、`mtx-security`、`mtx-dataretention`、`mtx-messaging`
- `trade-common`、`trade-storage-api`、`trade-storage-local`
- Web、Validation、Actuator、Prometheus、Redis
- MyBatis-Plus、MySQL 驱动
- Nacos Discovery
- `eleme-openapi-sdk`
- OpenFeign、LoadBalancer

Ingress POM **没有** `spring-kafka`。所以「回调主链路用 Kafka」没有依赖证据。分析通知的立即入队代码在 `AnalysisEventDeliveryService`，配置注释要求 Redis 库和 Ingress 的 Analysis Pub/Sub 一致。等级：已确认 Ingress 依赖 Redis；Kafka 是否也被 Ingress 间接带到运行时，待用依赖树确认。

### Analytics

在 Ingress 同类依赖之外，明确增加：

- `spring-kafka`
- `mtx-scheduled`
- `mtx-messaging` 版本 1.1.1，和根 POM 的 `mtx-core.version` 1.0.1 不同

Analytics 负责 Doris JDBC 和 Doris Stream Load。`DorisCanonicalFactWriter` 同时持有 JDBC 写入和 `DorisStreamLoadClient`。生产 YAML 里 `target-modes.v1` 是 `STREAM_LOAD`，`default-mode` 是 `JDBC`。含义是：默认模式和 v1 目标模式在配置里同时存在。哪条路径对哪张表生效，要看 `DorisStreamLoadProperties.enabledFor`，本轮只确认两种模式都在代码和配置里出现。

### Query

`trade-query/pom.xml` 描述为读取查询模板并执行 Doris 只读查询。依赖有 Web、OpenFeign、LoadBalancer、Nacos、MyBatis-Plus、MySQL。没有在已读 POM 片段里看到 `spring-kafka`。Query 是否连接 Redis，本轮未读完它的全部配置，标待确认。

## 4. Redis、Kafka 各干什么

已从代码确认的用途，不是 Redis 的全部 key：

| 组件 | 已看到的用途 | 类或配置 |
| --- | --- | --- |
| Redis | 富智云失败恢复的分布式锁 | `FuiouRecoveryPushScheduled` |
| Redis | 分析侧同一条广播只被一个实例处理 | `AnalysisPubSubDeliveryLock` |
| Redis | 同一订单写入互斥 | `OrderWriteLease` |
| Redis | 门店资料缓存、品牌会员 openId 缓存、映射补偿租约 | `ShopInfo` 缓存、`BrandMemberOpenIdCache`、`MappingCompensationEntityLease` |
| Redis | Ingress 与 Analytics 的分析事件即时通知所在逻辑库必须一致 | `trade-analytics-infra-prod.yaml` 注释 |
| Kafka | 事实刷写通知，主题名 `flushTaskToDoris`，5 个分区 | `FlushKafkaConfiguration` |
| Kafka | 补拉到期通知，主题名 `tradePickupDue`，2 个分区 | `PickupKafkaConfiguration` |

主订单事实不是「回调 HTTP 直接丢进 Kafka 再消费」。已确认的主路径是：HTTP 回调写入 MySQL 来源事件和 Outbox，再立即通知 Analytics；通知失败时 Outbox 还在，由拉取任务补。Kafka 出现在刷写和补拉唤醒。

没有发现 RocketMQ、RabbitMQ 的依赖声明。等级：当前 POM 范围内未发现。不能据此说历史上从未使用。

## 5. JSON 与 HTTP 调用形态

- 富智云订单和支付入口的参数类型是 `@RequestBody String payload`，不是强类型 DTO。解析在 `FuiouOrderPayloadParser`、`FuiouPaymentPayloadParser`。
- 京东回调 `consumes = application/x-www-form-urlencoded`，body 也是原始字符串。
- 美团、淘宝闪购同样先接收原始 body。
- 内部管理接口才较多使用请求对象，例如查询执行的 `ExecuteRequest`、团购同步的 `SyncCommand`。

因此「请求 DTO」不能理解成每个外部平台都有一个公开的 Java 请求类。外部契约首先是原始报文字节。

## 6. 和其他文档数字的差异

`AGENTS.md` 写了 MySQL 8.0.45、Redis 7.0.5、Doris 4.0.7。本轮没有在 POM 或 JDBC URL 里看到这三个服务器版本号。驱动版本 8.3.0 也不等于服务器版本 8.0.45。服务器版本保持待确认。

- 没有读取实际 Nacos 上的运行配置。仓库 `nacos/` 是代码里的生产基准。
