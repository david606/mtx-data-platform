## 7. 模块归属

ADR-0002 允许 `platform-quality` 和 `platform-transform` 只依赖 `platform-common` 与 `platform-core`。两个 POM 与此一致，没有 Spring、JDBC、MyBatis、Kafka、Quartz、Redis、MySQL 或 Doris。

Pipeline 只依赖 `platform-common` 和 `platform-core`，不依赖这两个实现模块。`app-worker` 可以依赖它们，但当前没有调用。没有反向依赖，也不需要新模块。

将来若有已确认的纯规则，质量规则放在 `platform-quality`，值转换放在 `platform-transform`。在规则未确认前，不把空模块当成已经拥有引擎。
