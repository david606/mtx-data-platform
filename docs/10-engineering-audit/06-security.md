# 06 安全

| 检查项 | 结论 | 证据 |
| --- | --- | --- |
| 租户隔离 | 未发现实现 | Java 与配置中无 tenant 字段、拦截器或数据源路由 |
| 敏感信息保护 | 未发现密钥材料 | `application.yml` 只有应用名。全仓库检索无口令、私钥块或 Token 字面量。这也说明还没有凭据管理实现 |
| API 权限 | 未发现实现 | 无 API，无 Spring Security 依赖 |
| Worker 身份认证 | 未发现实现 | 无 Worker 模块和身份代码 |

现有启动路径没有认证层。因为没有对外接口，当前风险是“能力缺失”，不是“已暴露未授权接口”。接口一旦增加而没有同步增加认证，会变成直接风险。
