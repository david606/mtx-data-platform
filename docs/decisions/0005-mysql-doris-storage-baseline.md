# 0005. MySQL 与 Doris 存储基线

- 状态：已接受
- 日期：2026-11-25
- 范围：事务型元数据的数据库产品与服务器版本，以及 Apache Doris 的服务器版本。不包含驱动、连接池、字符集、排序规则、事务隔离级别、物理表、DDL 或工程接入。

本决策不修改 [ADR-0003](0003-unmapped-conflict-observation.md) 和 [ADR-0004](0004-external-contract-version-resolution.md) 的金额处理规则。

## 决策

| 技术 | 版本 | 本决策中的状态 |
| --- | --- | --- |
| MySQL | 8.0.46 | 已接受的目标技术基线 |
| Apache Doris | 4.0.7 | 已接受的 OLAP 服务器版本基线 |

MySQL 当前基线只写 8.0.46。不使用笼统的 8.0，不把旧生产环境的 8.0.45 写成 V2 目标版本，也不把 MySQL 8.4 写成已经接受的版本。

Doris 4.0.7 是服务器版本。它不承担任务终态、配置发布、审计权威或原始报文正文。客户端和驱动版本仍未锁定。`trade-flow` 调查里出现的 `doris-4.0.7-rc02` 构建标识是旧系统证据，不是本决策锁定的构件。

## 版本确定与工程接入

服务器版本已经确定，工程接入尚未完成。

已经确定的是目标产品版本。尚未完成的是：模块依赖中的数据库驱动、连接配置、库和账号、已批准的物理表，以及在 JDK 25 上的连通验证。根 POM 目前没有 MySQL 驱动或 Doris 客户端。没有已确认的 DDL。

以下事项继续未决，本决策不指定它们：

- MySQL 驱动版本
- 连接池实现和参数
- 字符集
- 排序规则
- 事务隔离级别

Redis 和 Flyway 不在本决策范围内，仍未选定。

## MySQL 8.0.46 生命周期与维护风险

这是已接受基线的正式架构风险。选择 8.0.46 是本决策的事实。本决策不把目标版本改成 8.4，也不把未来升级写成无风险的直接替换。

2026-11-25 核验的两份 Oracle 资料使用了不同术语，不能合并成一种支持状态：

| 资料 | 原文结论 | 不能据此写成 |
| --- | --- | --- |
| [MySQL 8.0 Release Notes](https://dev.mysql.com/doc/relnotes/mysql/8.0/en/) | 自 2026 年 4 月起，随版本 8.0.46，MySQL 8.0 进入 End of Life（EoL）。发布说明收录至 8.0.46，目录没有更高的 8.0 版本。建议升级到最新 MySQL 8.4 LTS 或 MySQL Innovation 版本 | 8.0.46 仍在发布新的公开维护版本 |
| [MySQL 8.0.46 发布说明](https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-46.html) | 8.0.46 的发布日期是 2026-04-21 | 该日期等于已经完成 V2 连通验证 |
| [MySQL Product Support EOL Announcements](https://www.mysql.com/support/eol-notice.html) | 自 2026-04-21 起，MySQL 8.0 进入 Oracle Lifetime Sustaining Support。该则公告建议升级到 MySQL 8.4 LTS 或 9.7 LTS | Sustaining Support 等于常规维护支持，或等于产品立即不可用 |

三个词在本决策中分开使用：

- End of Life 是 8.0 发布说明对这条公开版本线的结论。8.0.46 是该发布说明收录的最后一个 8.0 版本。
- Sustaining Support 是支持公告对 8.0 使用的支持阶段名称。上述页面没有列出该阶段仍提供哪些新补丁。
- 常规维护支持指该系列仍继续发布新的公开功能修复和安全补丁。本决策不把 8.0.46 描述为仍处于这种状态。

9.7 LTS 只出现在支持公告的升级建议里。它不是本项目的目标版本，也不代替以后对 8.4 LTS 的评估。

风险处理：

1. 后续若考虑升级到 MySQL 8.4 LTS，必须另做兼容性评估，并另有已接受决策后才能更换基线。评估至少包括驱动、SQL 语义、字符集和排序规则、已有数据的升级路径，以及应用在 JDK 25 上的验证。不能假设可以直接升级。
2. 生产上线前必须重新核验安全维护和支持条件。本次核验只说明 2026-11-25 的公开页面，不代表上线当日的支持合同或补丁状态。
3. 接受这项生命周期风险的责任人尚未确认。本决策不虚构审批人或审批记录。

MySQL 8.4 参考手册中的语句、分区或 JSON 行为，不能写成 MySQL 8.0.46 已经验证的能力。
